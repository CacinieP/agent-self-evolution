## 一句话总结
专门评测 Agent 长期记忆能力,衡量记忆管理策略对多步任务的影响。

## 核心方法
构造需要跨多个任务会话积累知识才能完成的任务,评估不同记忆策略的效果。

## 关键贡献
首个专注于 Agent 记忆能力评估的基准,量化不同记忆管理方案的优劣。
