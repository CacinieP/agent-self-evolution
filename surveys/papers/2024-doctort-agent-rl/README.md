## 一句话总结
用 RL 训练医疗 Agent 在诊断中做出最优决策序列。

## 核心方法
将医疗诊断建模为序列决策问题,用 RL 优化 Agent 的诊断策略,避免有害决策。

## 关键贡献
RL 训练的医疗 Agent 在诊断准确性和安全性上显著超越 SFT baseline。
