## 一句话总结
多 Agent RL 系统用于医疗诊断,优化诊断决策序列。

## 核心方法
将医疗诊断建模为序列决策问题,用多 Agent RL 优化诊断策略。

## 关键贡献
RL 训练的医疗诊断 Agent 在准确性和安全性上显著超越 SFT baseline。
