## 一句话总结
用进化搜索自动编排多工具 Agent 执行流程,无需人工设计编排策略。

## 核心方法
将 Agent 编排策略编码为可进化结构,通过遗传算法搜索最优工具调用序列和决策分支。

## 关键贡献
自动化 Agent 编排设计,在复杂工具链任务上超越手工编排的性能。
