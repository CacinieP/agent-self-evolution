## 一句话总结
DeepMind 的编程 Agent 通过自进化算法搜索并优化科学计算代码,辅助科研发现。

## 核心方法
结合 LLM 代码生成与进化搜索(变异+选择),在科学发现空间中自主探索并改进代码解。

## 关键贡献
展示 AI Agent 在科学计算领域的自进化能力,发现超越现有文献的数值解。
