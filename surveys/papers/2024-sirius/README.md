## 一句话总结
多 Agent 通过引导推理实现自改进,无需外部反馈。

## 核心方法
Agent 通过自举推理(bootstrapped reasoning)迭代改进输出,在无外部反馈场景下实现自进化。

## 关键贡献
自举推理驱动的多 Agent 自改进在 NLP 任务上验证效果。
