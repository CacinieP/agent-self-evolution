# Gödel Agent: A Self-Referential Agent Framework for Recursive Self-Improvement

- **作者**: (Google DeepMind)
- **发表**: arXiv:2504.00924 (2025)
- **链接**: https://arxiv.org/abs/2504.00924

## 一句话总结
构建自我指涉的 Agent 框架,支持对自身策略进行递归式的自我改进。

## 核心方法
Agent 可读取和修改自身的推理策略代码,通过"自我修改-自我验证"循环实现递归式改进。

## 关键贡献
证明递归式自我改进在受限场景下可突破初始能力边界,探讨自引用系统的安全边界。
