# Navi: Windows Agent Arena for Multi-App Web Agents

- **作者**: Bonatti et al. (2024)
- **发表**: arXiv:2409.08264 (2024)
- **链接**: https://arxiv.org/abs/2409.08264

## 一句话总结
在真实 Windows 环境中评估多应用 Web Agent。

## 核心方法
构建包含 150+ Windows 应用的完整环境,Agent 通过交互学习跨应用操作策略。

## 关键贡献
首个大规模 Windows 多应用 Agent 基准,揭示当前 Agent 在桌面环境中的能力边界。
