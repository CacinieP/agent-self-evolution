## 一句话总结
导航 Agent 通过视觉-语言理解自主探索环境,在失败中学习导航策略。

## 核心方法
Agent 结合视觉观察和语言指令生成导航动作,从探索失败中提取经验改进后续路径规划。

## 关键贡献
视觉-语言导航中的自进化策略,在未见环境上提升零样本导航成功率。
