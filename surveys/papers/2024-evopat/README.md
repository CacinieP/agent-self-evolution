## 一句话总结
通过动态演化患者档案丰富医疗 Agent 训练,提升诊断泛化性。

## 核心方法
生成多样化演化患者档案,Agent 在这些档案上训练后可泛化到 unseen 病例。

## 关键贡献
患者档案的动态演化是医疗 Agent 自进化的关键,显著提升跨病例泛化。
