# ReAP: Reflection-Augmented Planning for Web Agents

## 一句话总结
通过反思增强规划,Web Agent 在执行中自我优化行动策略。

## 核心方法
Agent 在执行中评估每个操作的价值,通过反思机制动态调整后续计划。

## 关键贡献
反思增强规划在复杂 Web 任务上减少操作步数同时提升成功率。
