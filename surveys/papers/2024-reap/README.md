## 一句话总结
Web Agent 通过推理-动作剪枝减少无效操作,在执行中自我优化行动策略。

## 核心方法
Agent 在执行中评估每个操作的价值,动态剪枝低价值推理分支,聚焦高收益操作。

## 关键贡献
推理-动作协同剪枝在复杂 Web 任务上减少操作步数同时提升成功率。
