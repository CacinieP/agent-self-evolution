## 一句话总结
通过进化算法优化多 Agent 协作模式,在代码生成任务上自进化 Agent 团队。

## 核心方法
多个代码 Agent 通过遗传算法进化协作策略(角色分配/信息传递/代码审查),在 benchmark 上自评自选。

## 关键贡献
证明进化多 Agent 协作可在代码生成上超越固定角色分配,实现团队级的自进化。
