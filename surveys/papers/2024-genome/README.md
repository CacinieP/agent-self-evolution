## 一句话总结
用遗传算法进化多 Agent 系统架构,在开放-ended 环境中实现架构自演化。

## 核心方法
将多 Agent 架构编码为基因组,通过选择/变异/交叉操作迭代搜索最优协作拓扑和策略组合。

## 关键贡献
开放-ended 遗传搜索可发现超越人工设计的 Agent 协作模式,在复杂环境中验证涌现行为。
