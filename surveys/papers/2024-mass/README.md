## 一句话总结
多 Agent 通过自我博弈在协作任务中自进化,无需人类示范。

## 核心方法
多个专用 Agent 在协作任务中自博弈,通过对手模拟和协同策略优化不断改进。

## 关键贡献
自博弈驱动的多 Agent 协作在需要复杂角色分工的任务中涌现高效策略。
