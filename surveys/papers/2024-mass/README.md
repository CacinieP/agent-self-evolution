## 一句话总结
联合优化多 Agent 系统的角色提示与通信拓扑的多阶段搜索框架。

## 核心方法
先优化个体角色提示,再精化 Agent 间通信模式,交替搜索复杂的 MAS 设计空间。

## 关键贡献
揭示提示与拓扑对 MAS 性能的共同影响,实现系统级自动设计。
