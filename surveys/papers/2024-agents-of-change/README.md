## 一句话总结
构建可自我进化的 Agent 生态系统,Agent 间通过协作和竞争共同进化。

## 核心方法
Agent 生态系统中引入生态位分化机制,Agent 根据各自专长自主选择任务并竞争资源,系统整体涌现自进化。

## 关键贡献
生态启发式 Agent 系统在多任务场景下实现系统级自进化和鲁棒性。
