## 一句话总结
GUI Agent 通过迭代自改进方法持续提升移动界面操作能力。

## 核心方法
Agent 在 GUI 交互中自动收集失败案例,通过自反思和策略调整迭代改进。

## 关键贡献
自改进 GUI Agent 在多个移动应用上验证。
