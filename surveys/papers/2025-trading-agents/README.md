## 一句话总结
多 Agent 市场模拟中,交易 Agent 通过市场反馈自我改进策略。

## 核心方法
构建包含分析师/交易员/风控的 Agent 团队,在市场模拟中通过盈亏信号驱动策略自进化。

## 关键贡献
多角色 Agent 协作下的策略自进化在真实市场回测中验证有效性。
