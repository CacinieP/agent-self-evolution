# WebVoyager: Exploring Web Agents with Real-World Tasks

- **作者**: Junpeng Lao et al.
- **发表**: arXiv:2407.20249 (2024)
- **链接**: https://arxiv.org/abs/2407.20249

## 一句话总结
Web Agent 在真实网站上执行任务时自主学习网页结构和交互模式。

## 核心方法
Agent 在真实 Web 环境中的交互经验自动编码为可复用模式,构建自我进化的 Web 理解模型。

## 关键贡献
真实世界 Web 任务上的自我学习证明 Agent 可从实际使用中持续改进 Web 操作能力。
