## 一句话总结
Web Agent 在真实网站上执行任务时自主学习网页结构和交互模式。

## 核心方法
Agent 在真实 Web 环境中通过视觉-语言交互完成任务,在交互中积累网页操作经验。

## 关键贡献
真实世界 Web 任务上的自我学习证明 Agent 可从实际使用中持续改进。
