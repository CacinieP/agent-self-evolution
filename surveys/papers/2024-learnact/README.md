# LearnAct: Empowering Large Language Model Agents through Action Learning

- **作者**: Zhao et al. (2024)
- **发表**: arXiv:2406.13981 (2024)
- **链接**: https://arxiv.org/abs/2406.13981

## 一句话总结
Agent 自主学习和生成 Web 操作动作空间。

## 核心方法
从成功轨迹中提炼有效的网页操作模式,生成结构化动作空间定义。

## 关键贡献
将动作空间从静态定义转为可学习的动态生成。

## 维度速查 (TAXONOMY)
```
What:   Tool(Iterative refinement) + Context(Prompt)
When:   Inter-test-time × ICL
How:    Imitation · Offline · On-policy · Outcome
Where:  GUI/Web
Eval:   Adaptivity, Generalization
```
