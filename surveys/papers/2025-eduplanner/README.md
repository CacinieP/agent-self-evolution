# EduPlanner: LLM-Based Multi-Agent Systems for Customized and Intelligent Instructional Design

- **作者**: (Zc0812 等)
- **发表**: IEEE TLT 2025 / arXiv:2504.05370
- **链接**: https://arxiv.org/abs/2504.05370
- **代码**: https://github.com/Zc0812/Edu_Planner

## 一句话总结
教育域多 Agent 系统:评估者 + 优化者 + 题目分析师对抗协作,自动生成、评估、迭代优化个性化教学设计。

## 核心方法
三个 Agent 形成对抗/协作闭环:生成教学设计 → 评估 → 据反馈迭代优化;聚焦数学等学科的个性化教案生成。

## 关键贡献
教育域 LLM Agent 自我改进的代表,把"教学设计"变成可被 Agent 自动迭代优化的对象。

## 维度速查 (TAXONOMY)
```
What:   Architecture(Multi-Agent) + Context(Prompt/策略)
When:   Inter-test-time × ICL
How:    Reward-based(评估反馈) + Population(对抗) · Online · On-policy · Outcome
Where:  Specialized(Education)
Eval:   Adaptivity(教学设计质量)
```
