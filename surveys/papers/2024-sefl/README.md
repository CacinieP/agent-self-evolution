# SEFL: Harnessing Large Language Model Agents to Improve Educational Feedback

- **作者**: Zhang et al. (2025)
- **发表**: arXiv:2502.12927 (2025)

## 一句话总结
LLM Agent 通过自演化反馈闭环改进教育评估质量。

## 核心方法
Agent 分析学生回答中的错误模式,自动调整评估标准和教学内容,形成反馈驱动的自进化。

## 关键贡献
自演化反馈闭环减少教师负担,在标准测试上提升评估质量。
