## 一句话总结
在虚拟医院中,医疗 Agent 通过诊疗经验自主进化诊断和治疗策略。

## 核心方法
构建虚拟医疗环境,医生 Agent 通过接诊→诊断→治疗→反馈的循环积累经验并自我改进。

## 关键贡献
证明 Agent 可在虚拟医疗环境中通过自进化提升临床推理能力。
