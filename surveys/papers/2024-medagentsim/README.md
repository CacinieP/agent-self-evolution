# MedAgentSim: Self-Evolving Multi-Agent Simulations for Realistic Clinical Interactions

## 一句话总结
多 Agent 医疗模拟中,医生 Agent 从诊疗经验中自主进化。

## 核心方法
构建虚拟医疗环境,医生 Agent 通过接诊→诊断→治疗→反馈的循环积累经验并自我改进。

## 关键贡献
多 Agent 医疗模拟验证 Agent 可通过自进化提升临床推理能力。
