## 一句话总结
自动优化多 Agent 协作工作流,在搜索空间中自主发现最优执行策略。

## 核心方法
将工作流优化建模为搜索问题,用强化学习搜索最优 Agent 编排和执行策略。

## 关键贡献
自动化工作流设计在复杂多 Agent 任务上超越手工编排。
