## 一句话总结
LLM Agent 的自然语言工作流自动生成与优化框架。

## 核心方法
迭代优化程序自动生成/精化自然语言工作流,支持开源和闭源 LLM。

## 关键贡献
生成鲁棒可解释的 Agent 工作流,在多个 benchmark 上验证效果。
