# MLE-Bench: Evaluating Machine Learning Agents on Machine Learning Engineering

- **作者**: Chan et al. (2024)
- **发表**: arXiv:2410.07095 (2024)
- **链接**: https://arxiv.org/abs/2410.07095
- **代码**: —

## 一句话总结
在真实 Kaggle 竞赛上评测 ML Agent 的自主解决方案能力。

## 核心方法
使用 75 个过去 Kaggle 竞赛作为基准,Agent 需自主完成数据探索/特征工程/模型训练/提交全流程。

## 关键贡献
ML 工程 Agent 的首次系统性基准,揭示当前 Agent 在复杂 ML 工作流中的能力边界。
