# STELLA: Self-Evolving LLM-Based Tutoring Agents

- **作者**: Jin et al. (2025)
- **发表**: arXiv:2507.02004 (2025)
- **链接**: https://arxiv.org/abs/2507.02004

## 一句话总结
教学 Agent 通过自我评估和自适应课程实现教学能力的持续进化。

## 核心方法
Agent 根据学习进度自适应调整教学难度和内容,通过自我评估识别薄弱环节并针对性训练。

## 关键贡献
自适应教学闭环实现无教师干预的教学能力持续提升。
