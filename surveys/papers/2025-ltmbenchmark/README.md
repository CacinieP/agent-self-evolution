## 一句话总结
长期记忆基准,评测 Agent 在多任务序列中的知识积累和抗遗忘能力。

## 核心方法
设计连续多任务序列,Agent 需在任务间积累知识并防止遗忘,全面评估终身学习能力。

## 关键贡献
聚焦 Agent 长期记忆的评估基准,量化不同记忆管理策略的持续学习能力。
