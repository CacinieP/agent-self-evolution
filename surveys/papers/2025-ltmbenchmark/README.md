# Beyond Prompts: Dynamic Conversational Benchmarking of Large Language Models (GoodAI LTM Benchmark)

- **作者**: David Castillo-Bolado et al.
- **发表**: arXiv:2409.20222 (2024, NeurIPS 2024)
- **链接**: https://arxiv.org/abs/2409.20222
- **代码**: —

## 一句话总结
动态对话式基准,评测 LLM 的长期记忆(LTM)与持续学习:回忆、纠错与矛盾信息处理。

## 核心方法
11 类场景交错对话并注入干扰项,度量记忆跨度加权的 LTM Score 与效率(测试/小时、成本)。

## 关键贡献
自动化动态评测记忆保持与持续学习,支持跨架构公平对比。
