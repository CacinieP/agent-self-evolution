## 一句话总结
Agent 在执行过程中根据语言反馈自适应调整规划,实现实时计划自进化。

## 核心方法
在执行中根据环境反馈和语言评估动态重规划,自适应调整行动策略。

## 关键贡献
在线自适应规划在多步任务中显著优于静态预规划。
