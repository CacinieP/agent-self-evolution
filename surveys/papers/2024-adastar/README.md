## 一句话总结
自适应选择最优推理模板,Agent 在零样本场景下自举推理能力。

## 核心方法
Agent 根据问题类型自适应选择最有效的推理模板,通过自生成示范和筛选迭代改进。

## 关键贡献
自适应模板选择机制在零样本推理上显著优于固定模板方法。
