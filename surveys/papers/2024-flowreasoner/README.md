## 一句话总结
让 Agent 在推理过程中自主优化工作流,动态调整任务执行路径。

## 核心方法
在推理链中嵌入工作流规划器,根据中间结果评估动态重路由执行流程,逐步优化完成策略。

## 关键贡献
实现推理驱动的工作流自优化,在复杂多步任务上减少不必要步骤提升效率。
