## 一句话总结
用查询级元 Agent 动态优化工作流,根据输入自适应调整执行策略。

## 核心方法
为每个查询动态激活专用元 Agent,根据查询类型选择最优子 Agent 组合。

## 关键贡献
查询级自适应元 Agent 机制在多样化任务上提升整体效率。
