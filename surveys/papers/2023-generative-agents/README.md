# Generative Agents: Interactive Simulacra of Human Behavior

## 一句话总结
25 个 LLM Agent 在小镇中自主生活,通过自然语言记忆和反思演化出类人行为。

## 核心方法
三层记忆架构(观察→反思→规划)驱动 Agent 从原始交互中提取高层次洞察并指导未来行为,实现记忆驱动的自进化。

## 关键贡献
提出生成式 Agent 框架,在小规模社会模拟中验证记忆自组织和社会行为涌现。
