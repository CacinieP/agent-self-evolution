## 一句话总结
LLM Agent 通过自改进在量化交易中自主发现和优化交易策略。

## 核心方法
Agent 自主分析市场数据,生成交易策略,通过回测反馈自改进策略参数。

## 关键贡献
LLM 驱动的量化策略发现流程在回测中验证有效性。
