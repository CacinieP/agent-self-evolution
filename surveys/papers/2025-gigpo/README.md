## 一句话总结
用梯度优化和博弈论驱动多 Agent 策略协同进化,实现复杂多 Agent 任务的策略均衡。

## 核心方法
将多 Agent 训练建模为博弈均衡问题,用梯度方法和博弈论找到纳什均衡策略。

## 关键贡献
多 Agent 协同训练中的均衡求解框架,在竞争/协作场景下验证策略涌现。
