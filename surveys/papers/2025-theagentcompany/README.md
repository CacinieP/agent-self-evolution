# TheAgentCompany: Benchmarking LLM Agents on Consequential Real-World Company Tasks

- **作者**: Xu et al. (2024)
- **发表**: arXiv:2412.14161 (2024)
- **链接**: https://arxiv.org/abs/2412.14161

## 一句话总结
模拟真实公司办公环境,系统评估 Agent 完成复杂工作流任务的综合能力。

## 核心方法
构建包含文件系统/邮件/项目管理等工具的虚拟公司环境,定义多步骤办公任务序列。

## 关键贡献
将 Agent 评测从单一任务扩展到完整工作流,度量 Agent 在真实企业场景中的实用性。
