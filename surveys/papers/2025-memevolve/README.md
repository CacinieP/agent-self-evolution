# MemEvolve: Meta-Evolution of Agent Memory Systems

- **作者**: Zhang et al. (2025)
- **发表**: arXiv:2512.18746 (2025)
- **链接**: https://arxiv.org/abs/2512.18746

## 一句话总结
记忆系统的元进化,Agent 自动优化自身记忆管理策略。

## 核心方法
Agent 根据任务表现反馈自动调整记忆存储/检索/遗忘策略。

## 关键贡献
记忆元进化在多个任务上超越固定记忆管理策略。

## 维度速查 (TAXONOMY)
```
What:   Architecture(Single-agent) + Context(Memory)
When:   Inter-test-time × ICL
How:    Reward-based(记忆反馈) · Offline+Online · Mixed · Process
Where:  General
Eval:   Adaptivity, Retention
```
