## 一句话总结
通过 prompt 和拓扑的联合优化自动设计多 Agent 系统。

## 核心方法
同时优化 Agent 的 prompt 配置和通信拓扑,搜索最优多 Agent 协作配置。

## 关键贡献
联合优化 prompt+拓扑在多 Agent 任务上显著超越单独优化。
