## 一句话总结
用可微分架构搜索自动设计最优多 Agent 协作拓扑。

## 核心方法
将多 Agent 协作建模为可微分图网络,通过梯度搜索优化 Agent 间通信模式和任务分配策略。

## 关键贡献
将架构搜索引入多 Agent 系统设计,自动化发现比手工设计更优的协作拓扑。
