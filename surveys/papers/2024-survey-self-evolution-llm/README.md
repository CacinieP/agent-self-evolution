- **发表**: arXiv:2404.14387 (2024)
- **链接**: https://arxiv.org/abs/2404.14387

## 一句话总结
较早系统梳理 LLM 自进化(自反馈、自训练、自评测、自进化范式)的综述。

## 核心方法
提出"自进化循环"框架:经验获取 → 自反馈 → 自更新,并梳理范式与应用。

## 关键贡献
为后续 Agent 自进化综述提供"自反馈 / 自训练 / 自评测"的概念框架,本仓库早期 TAXONOMY 参考之一。
